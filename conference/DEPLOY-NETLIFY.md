# Публикация атласа для конференции

## Что важно знать
Эта карта использует внешние ресурсы Leaflet (unpkg.com) и картографическую подложку ArcGIS. Новый хостинг может помочь, если школьная сеть блокирует только GitHub, но не устранит блокировку этих внешних источников. Для надежного офлайн-показа нужна отдельная сборка с локальными библиотеками и картографическими данными.

## Развертывание на Netlify через подключение репозитория
1. Откройте https://app.netlify.com/ и войдите/создайте аккаунт.
2. Выберите **Add new site → Import an existing project**.
3. Подключите GitHub и выберите репозиторий `vwj8rh6b68-max/ancient-world-map`.
4. В настройках публикации оставьте:
   - Base directory: пусто
   - Build command: пусто
   - Publish directory: `.`
5. Нажмите Deploy. Netlify выдаст URL вида `https://<имя-сайта>.netlify.app`.
6. Откройте полученную ссылку на конференционной доске и проверьте масштабирование, перетаскивание и переключение эпох.

## Самая быстрая альтернатива — ручная загрузка
Если подключение GitHub не подходит, скачайте ZIP репозитория, распакуйте его и загрузите папку сайта через Netlify Drop: https://app.netlify.com/drop . Ручной Drop не синхронизирует будущие изменения автоматически.

## Проверка перед выступлением
- Откройте сайт на доске именно через школьную сеть.
- Проверьте не только загрузку HTML, но и внешний слой карты.
- Проверьте touch/мышь: перетаскивание, zoom, временной переключатель, выбор объекта.
- Если сайт открывается, а фон карты нет, школьная сеть может блокировать ArcGIS или unpkg — нужен офлайн-комплект.
- Сохраните резервную запись демонстрации и копию проекта на флешке.

## Локальный запуск
Для проверки на Windows откройте `index.html` или соответствующий файл карты в Edge/Chrome. Учтите: локальный HTML может по-прежнему загружать библиотеки и подложку из интернета, поэтому это не гарантированный офлайн-режим.
